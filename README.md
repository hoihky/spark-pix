# spark-pix

Agent skill + Python toolkit for **production-ready 2D pixel game art** — sprite sheets,
character animation atlases, props, VFX, and **Tiled tilesets** — built with **Pillow** and
exported for the [Spark](https://hoihky.github.io/spark/) game engine.

**Introduction (web):** [docs/index.html](docs/index.html) · **Agent entry:** [SKILL.md](SKILL.md)

## Production standard

Art targets **shippable indie quality** at **1×** resolution: readable silhouettes, stable
animation pivots, intentional palettes (8–24 colors), Spark-valid atlases and TSX tile props.
Workflow: brief → `build.py` → 8× preview critique (≥2 passes) → `validate` → deploy.
Full bar and routing: **[SKILL.md](SKILL.md)** · checklist: [references/validations.md](references/validations.md).

| Tier | Project | Use |
|------|---------|-----|
| Production reference | `pixel-art/vanguard_hero/`, `robot_ranger/` | Heroes, combat clips, projectiles |
| Production tiles | `pixel-art/example_tiles/` | TSX + Spark gameplay properties |
| Minimal sample | `pixel-art/example_slime/` | API smoke test only — not a humanoid template |

## Install

```bash
cd spark-pix   # repository root
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

(`pip install -r requirements.txt` works too; `-e .` enables `python -m sparkpix`.)

## Use as a Cursor skill

Copy or symlink this folder into your skills path, or open this repo in Cursor and
invoke the **spark-pix** skill. The agent reads `SKILL.md` and runs `build.py` workflows.

## CLI

```bash
python -m sparkpix palette show
python -m sparkpix palette export pixel-art/_shared/spark_game.palette.json
python -m sparkpix validate pixel-art/vanguard_hero/out
python -m sparkpix manifest summary assets/for-spark/slime.spark-atlas.json
python -m sparkpix study reference.png pixel-art/_study/ref
./scripts/audit_privacy.sh
```

## Shared palette

Use `from sparkpix.game_palette import GRASS, INK, SPARK_GAME, palette_for_sprite` in any `build.py`, or import via `pixel-art/_shared/game_palette.py`. Keep characters and tiles on the same ramps ([references/palettes.md](references/palettes.md)).

## Quick example (minimal)

```bash
PYTHONPATH=scripts python3 pixel-art/example_slime/build.py
python -m sparkpix validate pixel-art/example_slime/out
```

Production-style hero:

```bash
PYTHONPATH=scripts python3 pixel-art/vanguard_hero/build.py
python -m sparkpix validate pixel-art/vanguard_hero/out
```

Outputs: `out/*.png`, `*.spark-atlas.json`, previews/GIF as generated by each `build.py`.

## Spark deployment

Copy **1×** `out/*.png` and `*.spark-atlas.json` to your Spark tree:

`../spark/assets/sprites/<your-pack>/` (sibling checkout) or see [references/paths-and-privacy.md](references/paths-and-privacy.md).

Wire `SpriteAnimatorComponent` using grid size and clips from the JSON manifest
([references/spark-export.md](references/spark-export.md)), or run Spark demo **30 — Spark-pix atlas**
([spark-integration/INTEGRATION.md](spark-integration/INTEGRATION.md)).
