spark-pix

spark-pix is a Cursor agent skill and Python toolkit for production-ready 2D pixel game art with Pillow: character sprite sheets, flipbook animation, terrain tilesets, and projectiles at 1× for real games. Every asset is a regenerable build.py that exports PNG atlases, GIF previews, and .spark-atlas.json manifests for the Spark game engine SpriteAnimatorComponent.

Overview

spark-pix targets shippable indie quality for Spark’s 2D stack: uniform-grid sprite sheets, nearest-filter 1× textures, and Tiled TSX tilesets with gameplay properties. The skill enforces brief → rig-based drawing → 8× preview critique (≥2 passes) → validate → ship—without external paint tools or diffusion models.

Production bar

Readable silhouettes at 1×, stable animation pivots, 8–24 color palettes, named clips for code, and sparkpix validate before deploy.

Regenerable source

Art lives in pixel-art/<name>/build.py. Re-run to change palettes, poses, or clip timing—never hand-edit exported PNGs.

Humanoid rigs

64×64 side RPG heroes use filled limbs (≥2 px), rig-driven poses, and humanoid-hero rules—not stick figures or slime-scale templates.

Spark-ready export

save_spritesheet() writes *.spark-atlas.json aligned with SpriteAnimatorComponent uniform grids (frame 0 = bottom-left).

Agent + CLI

Load SKILL.md in Cursor, or run python -m sparkpix for validate, palette, manifest, and reference study helpers.

Agent workflow

The skill’s quality engine is see → critique → fix on scaled previews before shipping atlases.

flowchart LR
    Brief[Brief & references] --> Build[build.py + sparkpix API]
    Build --> Run[Run script]
    Run --> Preview[preview PNG / GIF]
    Preview --> Critique{Silhouette OK?}
    Critique -->|no| Build
    Critique -->|yes| Validate[sparkpix validate]
    Validate --> Ship[PNG + spark-atlas.json]
    Ship --> Spark[Spark assets/sprites/]

Spark engine integration

Copy built PNG + *.spark-atlas.json into your Spark tree at assets/sprites/<pack-id>/ (sibling repo convention: ../spark/assets/sprites/). Load with TryLoadSparkPixAtlasManifest or wire clips manually—see spark-integration/INTEGRATION.md and references/spark-export.md in the repo checkout.

SparkDemo includes menu entry Spark-pix atlas (demo #30) for sample slime atlases when the engine is built with bundled assets/sprites/spark_pix/ content.

Quick start

From the repository root:

python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .

# Production-style hero (recommended)
PYTHONPATH=scripts python3 pixel-art/vanguard_hero/build.py
python -m sparkpix validate pixel-art/vanguard_hero/out

# Minimal API smoke test
PYTHONPATH=scripts python3 pixel-art/example_slime/build.py
python -m sparkpix validate pixel-art/example_slime/out

Install the skill in Cursor from this repo (SKILL.md). Before sharing code, run ./scripts/audit_privacy.sh.
