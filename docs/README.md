# Documentation site

Open **[index.html](index.html)** for the project introduction (layout matches [Spark docs](https://hoihky.github.io/spark/)).

Content aligns with the **production quality standard** in the repo root `SKILL.md` and `references/validations.md`.

## GitHub Pages

Publish from the repository **docs/** folder (Settings → Pages → branch `main`, folder `/docs`).  
Site root: `https://<user>.github.io/<repo>/` (e.g. [spark-pix on GitHub](https://github.com/hoihky/spark-pix)).

Styles: `site/css/site.css`. Assets: `media/`.
