# Documentation site

Open **[index.html](index.html)** in a browser for the project introduction (layout matches [Spark docs](https://hoihky.github.io/spark/)).

## GitHub Pages

Publish from the repository **docs/** folder (Settings → Pages → branch `main`, folder `/docs`).  
The site root will be `https://<user>.github.io/<repo>/`.

Styles live in `site/css/site.css` (shared with Spark’s doc theme). Assets: `media/`.
